Домашняя обжарка кофе: выбор зёрен и помола

1. Выбор кофейных зёрен

Для домашней обжарки лучше выбирать:

  • Арабика - более ароматная, сбалансированная кислинка
  • Робуста - более крепкая, с горьковатым вкусом
  • Смеси - сочетание арабики и робусты для баланса вкуса и крепости
Совет: Начинайте с небольших партий (100-200г) разных сортов, чтобы найти свой вкус.

2. Степени обжарки

  • Светлая (Cinnamon) - лёгкая кислинка, зерно светло-коричневое
  • Средняя (Medium) - баланс кислотности и сладости
  • Тёмная (Dark) - горьковатый вкус, маслянистая поверхность
  • Очень тёмная (Italian) - сильная горечь, почти чёрные зёрна

3. Помол кофе

Выбор помола зависит от способа заваривания:

  • Грубый - для френч-пресса, холодного заваривания
  • Средний - для капельных кофеварок
  • Мелкий - для эспрессо-машин
  • Очень мелкий - для турки
Важно: Кофе лучше молоть непосредственно перед завариванием для сохранения аромата.

4. Оборудование для домашней обжарки

  • Сковорода (самый простой способ)
  • Воздушный попкорн-аппарат
  • Специальная домашняя кофейная ростер

Экспериментируйте с разными сортами, степенями обжарки и помола, чтобы найти идеальный вкус!
